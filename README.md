# SFML Calculator

A simple graphical calculator built with C++ and SFML 3.

## Features

- Graphical user interface using SFML.
- Addition, subtraction, multiplication, and division.
- Keyboard input for numbers and operators.
- Switch between the two input values using the Tab key.
- Calculate results using the Calculate button.

## Controls

| Key | Action |
|---|---|
| `0–9` | Enter numbers |
| `Tab` | Switch between A and B |
| `+ - * /` | Select an arithmetic operation |
| `Backspace` | Reset the currently selected value |
| Mouse click | Calculate the result |

## Requirements

- C++ compiler
- SFML 3
- Arial font (`arial.ttf`)

## About

This project was created as a learning project while exploring C++ and graphical application development with SFML.
